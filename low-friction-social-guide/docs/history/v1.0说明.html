版本范围

定位确定为：一份面向大学生和初入职场者的相处指南，讲清怎么做、怎么说，以及可能付出什么代价。

从五章二十条扩到十章六十条。原五章各增加两条，新增五章各六条，覆盖长期关系、社交礼节、协作表达、家庭关系与求职入职离开。原有二十条补充了关系、责任和承诺方面的情境分支，原条号保持不变。

依据状态

全部六十条仍是经验建议；没有新增学术验证、访谈或正式制度结论，也没有声称完整观看平台视频。初版调研资料作为选题背景保留。连续阅读版及 Skill 快照与分章正文一致。

“完整版”表示本次规划的十章内容和阅读功能已齐，并不表示覆盖所有人际情境或已获专业审核。研究支持与具体制度核实留待有对应出处时逐条增加，不为了给项目显得可信而添加不相关引用。

重点审查

  • 区分私人求助和职责内任务，不把拒绝写成通用答案。
  • 区分首次失误、反复失约与实际困难，不直接推断动机。
  • 写出感谢、回报、履约与补救，不只讨论防备和退出。
  • 求职、离职、借款等条目不编造法律时限、赔偿金额或文件效力。
  • 不保证话术不伤感情，不固定礼金、回复频率与跟进时长。
  • 具体建议、分支、后续处理与例外放在同一条中。

功能变化

更新章节、主题和对象筛选；所有关联条目可跳转；新增无须 JavaScript 的连续阅读页、打印入口和完整 Markdown 正文。构建脚本检查字段、重复字段、编号和交叉引用，再同步生成文件及 Skill。

根据自己的关系与条件选择做法。示例可以调整，经验建议未验证效果。

本指南参考 GitHub 用户 kkk-bot 的《人情世故指南》项目，并结合公开资料重新编写。项目结构另参考 HowToLiveBetter 的问题目录、统一条目、公开纠错与配套 Skill 思路。
