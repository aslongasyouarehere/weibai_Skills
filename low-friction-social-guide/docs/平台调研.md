## 初步观察（编辑判断）

1. 样本反复涉及拒绝、借钱、礼节和上下级沟通，适合作为首批选题；尚无数据证明这是全部受众最关心的问题。
2. 场景、对话和具体动作，比抽象的“提高情商”更容易转成可查阅条目。
3. 一些样本使用“必须”“永远”“万能”等表达。指南应补上关系背景、组织规则、例外和可能代价。
4. 不能把礼仪偏好当成法律义务，也不能把经验说法包装成心理学定律。
5. 应同时覆盖合作、感谢、履约和修复关系，避免全书只讲拒绝与防备。

## 首批待写场景

- 同学反复让你帮改作业或做 PPT，怎么确定帮助范围？
- 小组作业有人不做事，怎么分工、提醒并记录？
- 室友使用你的东西不归还，第一次怎么开口？
- 求助老师或学长，第一条消息怎么把事情说清楚？
- 对方没有回复，何时跟进，何时换渠道？
- 别人帮忙后，怎么感谢、反馈结果并署名？
- 答应的事情做不完，怎么提前通知和补救？
- 同事说“顺手做一下”，怎么确认任务与时间？
- 多个任务同时到来，怎么请负责人确认优先级？
- 被当众批评，怎么澄清事实并安排后续沟通？
- 自己犯错，怎么说明影响和修复计划？
- 不想参加聚餐或不喝酒，怎么表达？
- 第一次到别人家做客，怎么确认安排和礼节？
- 朋友借钱，怎么决定、拒绝或把约定说清楚？
- 帮人垫钱后，怎么提醒结算？
- 随礼超出预算，怎么处理？
- 被问工资、成绩、家庭情况，怎么保留隐私？
- 群聊发生分歧，什么时候转私聊、什么时候保留公开记录？
- 别人传播你的私人信息，怎么提出停止与删除要求？
- 关系出现误会，怎么核实、道歉和修复？

## 条目模板

场景 → 先确认的信息 → 可选动作 → 示例表达 → 成本与可能效果 → 例外 → 依据类型与来源 → 更新时间。

示例表达标明为作者拟写，不冒充平台原话。依据区分研究、制度、经验；没有证据时不填成功率。初版先覆盖校园和实习场景，再逐步扩展。
