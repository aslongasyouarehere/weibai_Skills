# 低内耗社交指南 V1.0

## 项目简介

进入社会之后，我们常常会因为人情世故而苦恼：不知道事情该怎么做，话该怎么说，也不清楚一个选择背后可能要付出什么代价。

**这是一份面向大学生和初入职场者的社交场景决策指南。它不只告诉你一句话怎么说，而是先帮助你看清目标、关系、已有约定与现实风险，再选择动作，并根据对方的实际回应继续调整。**

从合作、求助、拒绝，到金钱、礼节和冲突，每条都写清判断关键、行动前准备、第一步、表达参考、不同情境、可能收益、关系代价、例外与调整信号。希望帮助你把一件模糊的烦恼，整理成一次可以执行、可以观察反馈的选择。你可以选择相近场景试用，但不能跳过自己的关系、权力差异与现实条件。

10 章 67 条 · 全部为经验建议。

> **免责声明：仅供参考。** 本项目内容仅供学习与交流参考，属于经验建议，不保证适用于所有人或取得特定效果。具体问题请根据事实情况分析，结合自身处境、关系与适用规则独立判断，不宜直接照搬示例。

## 怎么读

- 打开 [阅读与检索页](index.html)，按关键词、场景和主题查找，也可以输入 `5.7` 等条号，或“怎么送礼”“借钱不还”等常见说法。搜索条件会保留在网址里，刷新或分享链接可以恢复。页面支持离线使用，不需要登录。
- 使用 HTML 页面时，请保留完整项目文件夹，再用浏览器打开 `index.html` 或 `阅读全文.html`。
- 打开 [连续阅读版](阅读全文.html)，从头阅读全部章节，并可用浏览器打印或保存为 PDF。
- 下载 [完整文字版](完整指南.md)，离线阅读或继续编辑。
- 不知道从哪里开始，先看 [使用指南](docs/usage.html)。
- 喜欢纯文字，可以按下面的问题读 `book/` 正文。
- 每条的“可以怎么说”都是本项目拟写的示例，不是平台原话，也不保证对方接受。
- 先用页面的“30 秒决策检查”整理目标、权力差异、已有约定、现实后果与替代方案，再查看相近条目。
- 展开“准备、不同情境、回应后怎么办与调整信号”，区分普通朋友、亲近关系、职责内请求等条件，别只照搬一句话。
- 本版没有经过系统访谈、行为测试或逐条研究验证。平台调研提供选题线索，不证明方法有效。涉及学校、单位和法律的具体要求，需要另查对应规则。

## 如何理解依据

不把经验、制度和研究放在一把尺子上打分，也不计算“情商分”或社交成功率。

| 类型 | 要求 | 本版情况 |
|---|---|---|
| 研究背景 | 原始研究来源、研究对象、主要结论与局限 | 已在部分条目注明背景与阅读范围；具体动作未逐条验证 |
| 制度规定 | 官方文本、适用地区或机构、截至日期 | 暂无具体制度结论 |
| 经验建议 | 标明为可选办法，列出代价、例外与失效可能 | 67 条 |

“可能换回什么”是编辑预期，不是已测得的效果。“花掉什么”包含时间、金钱、压力与关系代价。同一句话面对室友、老师、朋友或领导，效果可能不同。

## 给 AI 使用

配套 [低内耗社交指南 Skill](skills/低内耗社交指南/SKILL.md) 已包含一份正文快照。使用它回答具体场景时，先补齐会改变决定的事实，再查条目，输出第一步、可调整表达和对方不同回应下的下一步；查不到就说明缺项，不凭空补成“标准答案”。

例如：“用这份指南帮我处理：同学总让我改 PPT，我不想继续接。”本项目里的 Skill 尚未安装到你的全局技能目录。

## 编辑与生成

正文在 `book/`，每条的标签用于页面筛选。修改正文后运行：

```bash
python3 -m pip install reportlab pypdf
python3 tools/build_release.py
```

统一脚本会检查条目字段、连续编号和交叉引用，生成检索页、连续阅读页、练习与查阅页、完整 Markdown、PDF，并同步 Skill 正文快照。最后校验网页链接、PDF 条目书签和来源链接，避免发布旧的导出文件。版本与定位在 `project.json` 中维护。

PDF 默认使用 macOS 的中文字体。其他系统可给统一命令加上 `--font /path/to/chinese.ttf --bold-font /path/to/chinese-bold.ttf`，指定常规及粗体中文 TrueType 字体。只检查已生成文件时运行 `python3 tools/build_release.py --check`。搜索实现放在 `tools/search.js`，正文与标签仍以 `book/` 为准。

修改检索逻辑后，生成页面并运行 `node tools/test_search.cjs`，检查自然语言搜索、筛选与条目跳转的刷新状态；此检查需要 Node.js。
