# v1.7 饭局敬酒表达补充

日期：2026-10-03。更新 5.1，仍为 10 章 63 条，不改变既有条号。

补充朋友聚餐、感谢老师、感谢领导或前辈、同事庆功、祝福长辈、感谢组局者六类原创敬酒词，并保留不喝酒和不参加的表达。每段示例分别注明“仅供参考，请根据事实情况调整”。

敬酒表达以真实感谢、与场合有关的祝福为主；允许茶水或饮料参与，不把干杯、敬酒顺序、杯口高低或酒量作为通用义务。不夸大关系，不照搬未发生的帮助，不保证获得好感或照顾。均为原创经验建议，本次没有增加研究或制度结论。
