条号与自然语言搜索

修复条号被拆成两个数字的问题。输入 5.7、10.7 或 条目 5.7 时查找对应条目，不再匹配正文里无关的数字；不存在的条号不返回其他内容，章节与对象筛选仍然生效。

修复“怎么样送礼”残留“样”字的问题，并允许已登记的短语包含空格，例如“offer 催我答复”“申请延长 offer 回复期限”。补充被别人夸奖、转发截图、临时加班和室友使用物品的常见问法；未识别的实质关键词仍保留为搜索条件。

历史记录与 Skill 链接

过去部分历史核实记录被统一映射到最新记录，导致链接名称与打开内容不一致。现在为每份历史记录生成独立的阅读页，最新记录入口仍保留；下载项目 ZIP 后也可查看对应记录。

修复 Skill 平台素材笔记中指向不存在的“核实记录”目录的链接，改为随 Skill 附带的 v1.16 记录。统一发布检查增加 README 和 Skill 本地 Markdown 链接核对，并覆盖所有生成的文档阅读页。

验证范围

回归检查覆盖 67 条的条号与完整标题、常见问法、未知关键词、筛选、刷新、关联跳转、返回与前进、离线地址，以及历史记录指向的源文档。统一生成网页、Markdown、Skill 与 PDF 后，核对正文快照、页面链接与锚点、PDF 正文指纹和书签。
