# 编写与纠错规范

## 一条内容的最低要求

标题以动作开头。每条依次包含：遇到的情况、判断关键、行动前准备、先做什么、可以怎么说、分情境处理、花掉什么、可能换回什么、一个跟进字段、何时换办法、例外与代价、依据、相关条目。

统一字段不是为了把不同关系写成同一套答案，而是让读者完成一次判断。正文至少要覆盖这条决策链：**场景事实 → 目标 → 关系与权力条件 → 风险与可承担代价 → 第一动作 → 表达参考 → 对方回应后的下一步**。目标、关系、风险会随用户实际处境变化时，写进“判断关键”或“分情境处理”，不要给条目强行贴固定等级。

“分情境处理”说明会改变判断的条件，例如关系亲疏、第一次还是多次、职责内外、是否已有承诺、是否影响多人。不要每条都机械套用“对领导委婉、对朋友直接”；应解释为什么调整。

跟进字段可以是“如果对方继续要求”“如果决定借”等具体情境，不能只给一句话就结束。标签包含场景、对象、主题，用中文逗号或半角逗号分隔多值。

“判断关键”写会改变选择的具体问题，包括目标、关系、权力差异、已有约定、现实后果和替代方案中真正相关的部分；“行动前准备”写能实际准备的材料、约定、资源或替代安排；“何时换办法”写可观察的变化和对应动作。三者不能用同一套空泛提醒填满所有条目，不为普通交流增加无必要的记录、审批与防备。

跟进字段与“何时换办法”共同回答“对方回应后怎么办”。至少覆盖本条最关键的一种变化，例如继续施压、拒绝、没有回复、事实变化或约定没有落实。不要把一次表达当作交流终点。

《孙子兵法》仅为判断框架的思想来源。古文解释与现代生活转译须区分，不以经典权威提升依据等级，不默认人与人是敌对关系。

## 表达要求

先写可观察的事实与行为，再给建议。不把“没回消息”写成“不尊重你”，不把“提出请求”自动写成“利用你”。不规定未经支持的等待时长、送礼金额与关系回报。

经验不包装成科学。示例表达标为本项目原创，不冒充他人的逐字引用。话术可以直接、委婉或有条件答应，但需要说明选择的条件。

同时写成本与可能好处。接受别人帮助时尊重对方拒绝的空间，自己拒绝时也接受对方可能失望。协作、感谢、履约与修复关系，与拒绝同样重要。

不计算统一的“高性价比”“情商分”或成功率。需要比较方案时，分别说明：可能收益、关系压力、现实风险与可控程度，并写清判断依赖的事实。没有足够信息时明确说缺什么，不用伪精确分数替代判断。

## 来源要求

- 研究：给原始论文与可访问链接，区分观察关联与因果结果，写出对象与局限。
- 制度：优先给官方原文，注明地区、机构与核实日期。
- 经验：不虚构引用；平台文章只能证明作者提出过某种看法，不能证明其有效。
- 案例：匿名化，区分真实授权案例与编写情境。初版全部为编写情境。

## 纠错怎么提

提供“章节与条号 → 原句 → 哪里有问题 → 适用场景或反例 → 支持来源（如有）”。不要求经验反例必须有论文，但应说明情境，不提交个人身份信息。

修改实质结论后，在核实记录中留下原问题、改法、依据与尚未解决的问题。公开引用第三方内容前检查署名与许可要求。
