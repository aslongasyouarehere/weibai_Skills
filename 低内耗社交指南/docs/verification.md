# 低内耗社交指南 V1.0 改造记录

日期：2026-10-04。保留 10 章 67 条正文，本次不新增未经核实的建议，重点改造使用流程、页面呈现与配套 Skill。

## 从话术查找改为场景决策

新增“30 秒决策检查”，先整理目标、关系与权力差异、已有约定、现实后果和替代方案，再搜索相近条目。风险、关系压力和可控程度不做统一打分，由使用者根据当前事实判断，避免把不同关系强行归为同一等级。

条目卡片重新组织为“一句话判断、第一步、表达参考、行动前准备、根据关系调整、回应后怎么办、收益与代价、例外与依据”。原正文信息保持不变，只调整阅读顺序。

## 增加反馈闭环

使用指南与练习增加行动前决策卡、行动后反馈卡和跟进节点。一次表达不再视为终点；根据拒绝、沉默、继续施压、事实变化或约定未落实等可观察反馈，选择继续、调整、暂停、换渠道或求助。

## Skill 调用方式

Skill 先询问会改变选择的关键信息，再检索完整条目。输出包含当前判断、第一动作、不同语气的表达参考、回应分支、收益与代价、适用边界和引用位置。查不到相近内容时明确说明缺项；涉及高风险或具体制度时，提示核对适用规则或专业渠道。

## 验证范围

统一生成检索页、连续阅读页、文档阅读页、完整 Markdown、Skill 快照与 PDF。回归检查覆盖原有 67 条搜索、筛选、跳转与离线地址，并新增决策检查的生成与清除测试。

## 对外表述与参考说明

标题、简介、首屏和 Skill 描述只说明本指南的功能，不再使用“根据某指南回答”一类派生式表述。参考项目统一放在 README、网页页脚、完整指南、Skill 与 PDF 的末尾说明中。旧项目作者的赞赏入口不进入本版成品。
